# Dashboard Insights "View Details" Issue

## Root Cause

**"View details" is not interactive - it's just static text with no click handler.**

### Current Code
`frontend/src/components/InsightsBar.jsx` line 19:

```javascript
<span className="insight-row__action">View details</span>
```

**Problems**:
1. ❌ It's a `<span>`, not a `<button>`
2. ❌ No `onClick` handler
3. ❌ No state to track selected insight
4. ❌ No drawer/modal component to show details

### Why It Appears Clickable

The CSS (`.insight-row__action`) styles it to look like a link:
- Blue color
- Underline on hover
- Cursor pointer

But there's no actual click behavior implemented.

---

## Required Implementation

### 1. Make "View details" Interactive

```javascript
// Before
<span className="insight-row__action">View details</span>

// After
<button 
  type="button"
  className="insight-row__action"
  onClick={() => onViewDetails(item)}
>
  View details
</button>
```

### 2. Create InsightDetailsDrawer Component

**Features**:
- Slide-in drawer from right
- Shows insight details
- Action buttons (View Campaigns, View Keywords, Close)
- Reusable for all insight types

**Props**:
```javascript
<InsightDetailsDrawer
  open={Boolean(selectedInsight)}
  insight={selectedInsight}
  dateRange={dateRange}
  selectedApp={selectedApp}
  onClose={() => setSelectedInsight(null)}
  onViewCampaigns={() => navigate('/campaigns')}
  onViewKeywords={() => navigate('/keywords')}
/>
```

### 3. Add State Management

**In InsightsBar or parent Dashboard**:
```javascript
const [selectedInsight, setSelectedInsight] = useState(null)
```

## Insight Data Structure

Current insights generated by `generateInsights()`:

```javascript
{
  type: 'Trend' | 'Alert' | 'Growth' | 'Opportunity' | 'Info',
  text: 'CPA improved by 15.3% compared to the previous period.',
  tone: 'good' | 'bad' | 'neutral'
}
```

**Missing for details view**:
- Metric name (CPA, Spend, Installs, TTR)
- Current value
- Previous value
- Percentage change
- Related campaigns/keywords

---

## Solution

### Option A: Enhance Insight Objects (Recommended)

Modify `generateInsights()` to include structured data:

```javascript
{
  type: 'Trend',
  text: 'CPA improved by 15.3% compared to the previous period.',
  tone: 'good',
  metric: 'cpa',
  currentValue: 1.25,
  previousValue: 1.48,
  percentChange: -15.3,
  relatedCampaigns: [],
  relatedKeywords: []
}
```

### Option B: Extract from Text (Not Recommended)

Parse the text string to extract values. Fragile and error-prone.

## Implementation Approach

### Minimal (Phase 1)

Show basic information from current insight structure:
- Type
- Text
- Tone
- Date range
- Selected app
- Placeholder message for detailed drill-down

**Pros**: Quick, no changes to data generation  
**Cons**: Limited information

### Enhanced (Phase 2)

Enhance insight objects with structured data:
- Metric name
- Current/previous values
- Percentage change
- Can add related campaigns/keywords later

**Pros**: More useful information  
**Cons**: Requires modifying `generateInsights()`

---

## Recommendation

**Use Minimal Approach (Phase 1)**:
1. Create InsightDetailsDrawer
2. Show basic info + placeholder message
3. Add click handlers
4. Defer enhanced data to future update

This matches the user's instruction:
> "If no detailed data exists yet: Show a placeholder explaining that detailed drill down will be available in a future update"
