## 1. BID EXPERIMENT TENANT LEAK - **CRITICAL FIX APPLIED** ✅

### Issue Found

**Severity:** CRITICAL

**Problem:** `analyzeExperiment()` and related functions queried `daily_keyword_metrics` WITHOUT `organisation_id` filtering.

**Risk:** Two organisations with identical keyword identities would have their metrics MIXED in experiment analysis:
- Same `app_id`
- Same `campaign_name`
- Same `ad_group_name`
- Same `keyword_text`
- Same `bid_strategy`
- Same dates

This would cause:
- Org A seeing Org B's metrics
- Incorrect before/after calculations
- Cross-tenant data leakage in bid analysis

### Fix Applied

**File:** `backend/bidExperiments.js`

**Changes:**

1. **`queryKeywordDailyRows()`** - Added required `organisationId` parameter
   - Now filters: `WHERE organisation_id = $1 AND app_id = $2 ...`
   - Fails closed if `organisationId` missing

2. **`aggregateKeywordWindow()`** - Added required `organisationId` parameter
   - Passes to `queryKeywordDailyRows()`
   - Fails closed if `organisationId` missing

3. **`fetchHistoricalCpaSamples()`** - Added required `organisationId` parameter
   - Passes to `queryKeywordDailyRows()`
   - Fails closed if `organisationId` missing

4. **`analyzeExperiment()`** - Now requires `experiment.organisation_id`
   - Validates presence at entry
   - Passes to all helper functions
   - Fails closed if missing

5. **`detectBidExperiments()`** - Now filters by `organisation_id`
   - Background detection operates per-organisation
   - Query includes: `WHERE organisation_id = $1 AND ...`
   - Transitional fallback for backward compatibility

6. **`detectBidExperimentsForKeywordRecords()`** - Now requires `organisationId`
   - Called after import with import's `organisation_id`
   - Passes to `detectBidExperiments()`

7. **`backend/imports.js`** - Updated call site
   - Fetches `organisation_id` from import
   - Passes to `detectBidExperimentsForKeywordRecords()`

**Lines Changed:** 200+ lines across bidExperiments.js and imports.js

**Status:** ✅ **FIXED - All bid experiment queries now tenant-scoped**
